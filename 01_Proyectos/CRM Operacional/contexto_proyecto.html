Contexto
del Proyecto

Punto de partida, objetivos fundacionales y roadmap de implementación para el nuevo CRM operativo, destinado a reemplazar el portal interno "Galgo".

Dependencia Crítica: Integración con Telefonía CX (Genesys)

Este proyecto de CRM está fuertemente ligado a nivel de integración con el nuevo ecosistema de Telefonía CX (Genesys). Genesys actuará como el sistema maestro y motor principal de todas las comunicaciones corporativas, facilitando y sincronizando la información en tiempo real hacia Salesforce/Dynamics mediante integraciones nativas. El éxito de ambas plataformas depende de una coordinación absoluta en sus fases de despliegue y afectación mutua.

Contexto y Visión Global

Punto de situación, introducción y metas clave de la implantación

Situación Actual (Galgo)

  • Galgo actúa como frontal de desarrollo interno para el sistema Core Asegurador de LDA.
  • Soporta procesos centrales como cotizaciones, suplementos y retención.
  • No llega a cubrir las necesidades actuales de visión 360, agendas ágiles y omnicanalidad.

Objetivos del Proyecto

  • Implementar una solución de mercado (MS Dynamics o Salesforce).
  • Ejecutar un Plan de Gestión del Cambio y Formación para operadores.
  • Asegurar la transferencia de conocimiento hacia el CoE CRM de IT.

Consideraciones y Ecosistema

  • Convivencia temporal con Galgo mediante sincronización en tiempo real.
  • Integración nativa con CCaaS Genesys Cloud y nuevo Lakehouse Data.

Ecosistemas y Plataformas Mapeadas

Alternativas CRM en evaluación para la arquitectura objetivo

Microsoft Dynamics 365

Dynamics 365 (Sales & Service)

Integrado con O365 y Teams. Potenciado por Copilot. Requiere personalización para el sector seguros pero ofrece un licenciamiento muy competitivo.

✔ Fortalezas
  • Integración profunda con suite Microsoft y Teams.
  • IA Copilot ubicua y generativa.
✘ Debilidades
  • Poca profundidad aseguradora nativa (Out of the box).
  • Curva de desarrollo inicial más extensa.
Salesforce FSC (Vertical)

Financial Services Cloud

Específico para Seguros. Flujos y objetos pre-empaquetados (Household, Pólizas, Siniestros).

✔ Aceleración técnica

Reduce horas de desarrollo al usar el estándar de industria.

Salesforce S&S (Genérico)

Sales & Service Cloud

Pack tradicional agnóstico de industria. Requiere fabricar los objetos desde cero.

✔ Licencias Controladas

Coste por uso anual significativamente más reducido.
