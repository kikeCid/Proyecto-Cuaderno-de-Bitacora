Catálogo de servicios de aprovisionamiento, APIs de identidad y automatizaciones que mantienen la coherencia en tiempo real en todo el ecosistema de Línea Directa.

El Tejido Conectivo

El sistema GUS actúa como el sistema circulatorio de las identidades. No almacena datos maestros, sino que escucha eventos procedentes de RRHH (PeopleSoft) y orquesta órdenes técnicas (AD, OIM, Plantillas) de forma síncrona y asíncrona para que cada empleado comience a trabajar el Día 1 con todo lo necesario.

Mapa de Enlaces y Servicios

TalentLink ➔ PS

Activa

El equipo de Selección marca a un candidato en TalentLink como "Contratado". Esto lo inyecta en una cola de contratación (Queue). Un servicio interno de IT monitorea esta cola y sincroniza automáticamente los datos estructurales del futuro empleado en la base de datos de PeopleSoft.

Tipo Job Queue sync
Payload Datos Personales + Dept

PS Maestro ➔ GUS

Activa

Cada alta estructural ejecutada y finalizada en PeopleSoft (ya sea manual o vía integración con TalentLink) emite una señal que arranca el desarrollo a medida IT (GUS). A partir de aquí, IT abandona la capa de RRHH e inicia la capa puramente técnica del aprovisionamiento.

Tipo Event Trigger (Push)
Responsabilidad Disparador de Ciclo Técnico

GUS ➔ Dir. Activo (AD)

Core Sec

GUS orquesta la creación técnica del usuario en el Active Directory de Microsoft. Calcula la nomenclatura de red (LDA + iniciales + secuencial si hay duplicados), asigna las políticas de seguridad base y deja la identidad lista para hacer Login en los sistemas.

Tipo LDAP Create Object
Entorno Microsoft DC Domain

PS ➔ Oracle IAM (OIM)

Activa

Para agilizar la entrega de herramientas, un servicio específico de PeopleSoft avisa a la plataforma OIM (Oracle Identity Manager). OIM cruza la posición y área del usuario con sus matrices, y si existe una plantilla definida, aprovisiona automáticamente licencias, grupos de correo y CRM.

Tipo SOAP/REST Auth Event
